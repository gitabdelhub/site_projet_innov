# Chess Hub

Plateforme d'entraînement aux échecs, projet d'innovation ENSIAS.

**Site : https://site-projet-inno.vercel.app**

## Ce qu'on peut faire

- **Jouer contre l'ordinateur** (Stockfish, 9 niveaux).
- **Jouer en ligne** contre d'autres joueurs, avec un compte et un classement Elo.
- **Analyser une partie** coup par coup.
- **Connaître son Elo** : notre propre modèle d'IA l'estime à partir de nos parties.
- **Faire des puzzles** adaptés à son niveau.
- **Suivre sa progression**.

Le site est en français et en anglais.

## Lancer en local

Il faut Node.js 18 ou plus.

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.
